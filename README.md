
# snRNAseq-analysis

**snRNAseq-analysis** is a tutorial and analysis pipeline for processing and analyzing single-cell and single-nucleus RNA sequencing (scRNA-seq/snRNA-seq) data. This project aims to identify cell populations that co-express G protein-coupled receptors (GPCRs) and nuclear hormone receptors (NHRs).

The analysis is built using **Scanpy**, a powerful and scalable toolkit for single-cell transcriptomics in Python.

---

## 🚀 Features

- Analyze both single-cell and single-nucleus RNA-seq datasets.
- Identify co-expression of GPCRs and NHRs across cell types.
- Modular Python scripts using Scanpy and AnnData.
- Visualize gene expression and clustering results.
